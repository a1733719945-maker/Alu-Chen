把 Boss 模型放在这个文件夹，游戏会自动用它替换原来的 Boss 外形（没有就用原来的）。

文件名（必须一样）：
  mandala.glb    第一章 镜湖之主 · 千年碧鳞蛟
  spider.glb     第二章 落霞林之主 · 千目蛛母
  titan.glb      第三章 苍梧之王 · 万年朱厌
  icedragon.glb  第四章 朔北之主 · 万年冰螭
  whale.glb      第五章 玄鲲

怎么做：豆包 / Gemini 生成设定图（全身、白底）→ Tripo3D（tripo3d.ai）或 Meshy（meshy.ai）"图片生成 3D" → 导出 GLB（带贴图）。
大小、位置游戏会自动调；有动画的话，名字里带 idle / attack / run 的会自动用上。
面朝方向如果反了，告诉 Claude 转一下。
