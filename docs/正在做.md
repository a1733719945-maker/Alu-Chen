# 正在做（两个账号同时开工的登记表）

用户有两个 Claude 账号同时在做这个项目（**大号**：claude.ai/code 云端会话；**小号**：本机 Windows 桌面会话），用户想到什么就随时跟其中一个说。

**规矩**（两边都照做）：
1. 开工前先 `git pull --rebase`，看一眼下面的表，**别做对方正在做的事、别改对方列出的文件**（实在要改，在表里写一句）
2. 开工时在表里加一行，单独提交推送（提交说明带 `[skip ci]`）
3. 提交要小、勤推；推送被拒就 `git pull --rebase --autostash` 再推；冲突时两边的改动都保留，别覆盖对方的
4. `CLAUDE.md` 版本历史编号撞了就按时间先后顺延
5. 做完（推送了）或放弃，把自己那一行删掉
