# Meshy / Tripo 模型提示词（2026-09-29）

免费 CC0 素材库里找不到像样的中式人物、手、暗器，所以这几样请你用 Meshy（或 Tripo）生成。
建筑、码头、灯笼、材质这些我已经自己用 CC0 贴图做了，不用你管。

**通用设置**：风格选写实（Realistic），导出 **GLB、带贴图（PBR textures）**，面数中等（10k~30k）。
**放哪里**：生成好的 GLB 直接放进本机仓库的 `tools\incoming_models\` 文件夹（`文档\Alu-Chen\tools\incoming_models`），文件名按下面写的起。放好告诉我一声，缩放、朝向、压缩、接进游戏都由我来做。

按优先级排（前三个最影响观感）：
