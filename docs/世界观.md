# 苍墟 · 猎灵 —— 世界观

（原创设定。取材于中国修仙小说的通行框架——天门、飞升、境界、洞天、妖兽内丹——和《山海经》《庄子》《列子》这些公版古籍，不用任何现代小说的专有名词。）

## 一、天倾

上古之时，天有九重。人间与九天之间立着一座**天门**：修士证道，踏门飞升；天上的清灵之气也顺着天门流回人间，四时有序，万兽安驯。

三万年前，九天之上生了变故。史书只留下两个字——**天倾**。

那一夜星河倒灌，天门崩碎。撑住天地的**天枢**碎成五块，坠入凡间。大陆随之四分五裂，沉进云海，只剩一座座孤岛漂在茫茫水天之间。后人把这片破碎的大地，叫作**苍墟**。

## 二、灵兽与灵环

天门一断，灵气回不去天上，只能积在人间。草木禽兽吸得久了，开了灵智、结了灵核，成了**灵兽**。

灵兽活得越久，体内灵气凝得越厚，死后便化成一圈光环——**灵环**。

| 年份 | 灵环 |
|---|---|
| 十年 | 碧色，薄如晨雾 |
| 百年 | 蔚蓝 |
| 千年 | 紫气缭绕 |
| 万年 | 金光冲霄 |
| 十万年 | 赤如烈日 |
| 百万年 | 七彩流转，传说中才有 |

人也在变。苍墟的孩子到了六岁，体内会醒来一道**本命灵相**——青冥藤、玄月镰、灵葫、啸风白虎、玄夜灵猫、朱雀、九层玲珑塔、镇岳锤、九天玄女。灵相是修行的根；可人的经脉承不住天地灵气，每冲一个大境界，都得**炼化一枚灵环**，借兽之灵，开己之脉。

修士与灵兽，一猎一养，纠缠了三万年。

## 三、境界

每十级一个大境界，每个大境界的门槛上都要炼化一枚灵环，而且一环比一环要的年份高：

炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 真仙 →（飞升）

灵环给的**神通**，由你的灵相和那只灵兽共同决定——同一个灵相猎同一种灵兽，永远悟出同一门神通。所以猎哪一只，是修士一辈子最要紧的选择之一（猎灵榜上写明了会悟出什么）。

## 四、五大灵主

五块天枢碎片，被五头上古灵兽吞进了腹中。碎片不灭，吞了它的兽也就不老不死，各据一方：

| 岛 | 灵主 | 来历 |
|---|---|---|
| 镜湖 | **千年碧鳞蛟** | 三千年未曾离湖，湖底压着第一块碎片 |
| 落霞林 | **千目蛛母** | 千只眼睛，一张网。林子里的每一根丝都连着它 |
| 苍梧林海 | **万年朱厌** | 《山海经》："见则大兵。"它一睁眼，天下便起刀兵 |
| 朔北冰原 | **万年冰螭** | 它呼一口气，一整片海就冻成了冰原 |
| 归墟 | **十万年玄鲲** | 众水归处，名曰归墟。"北冥有鱼，其名为鲲" |

天枢碎片在它们体内一刻不停地往外渗灵气。灵气满了就溢——每隔十几年，苍墟就要闹一次**兽潮**：万兽发狂，沿岸的村子一夜之间就没了。这些年，兽潮一次比一次来得早。

## 五、栖霞村与青崖子

你生在镜湖边的**栖霞村**。村口有座塌了半边的古天坛，守坛的是个独眼老猎人，村里人叫他**青崖子**。

你醒来本命灵相那天，青崖子把你叫到坛前：

> "兽潮一次比一次早了。那五块天枢，快压不住了。
> 三万年没人飞升，不是天太高——是门碎了。门的碎片，就在那五头畜生的肚子里。
> 去猎灵，去炼环，把境界一层一层冲上去。等你扛得住天枢的威压，就来天坛前，把它们一个一个叫出来。
> 五块碎片凑齐那天，天门重开，灵气归天，兽潮就停了。
> ……那一天，你也就飞升了。"

## 六、游戏里的每样东西是什么

| 游戏里 | 世界观里 |
|---|---|
| 等级 / 修为 | 境界。每十级一个大境界，门槛上要炼化一枚灵环（瓶颈） |
| 猎灵榜（L） | 各岛猎户和宗门挂出来的悬赏：哪只灵兽伤了人、谁缺哪一环 |
| 猎场 | 灵兽聚居的荒野岛屿，灵主的眷属也在那里游荡 |
| 秘境 | **洞天碎片**：天倾时从九天坠下的小洞天，悬在岛的上空，里面的灵气浓得能凭空凝出兽来，是修士刷修为、寻灵骨的地方 |
| 天坛（祭坛） | 上古叩天之坛。境界够了，在坛前以灵力叩天，就能把本岛的灵主逼出来 |
| 灵主（Boss） | 吞了天枢碎片的上古灵兽。打倒它，夺回一块天枢碎片 |
| 千机阁（暗器铺） | 苍墟最大的机关暗器宗门，各岛都有它的铺子，营地也有补给 |
| 灵石 | 通行的货币，凝结的灵气 |
| 渡船 | 岛与岛之间只能坐船过云海 |
| 飞升 | 五块碎片归位、十环加身、真仙圆满：天门重开 |
| 转生 → **轮回** | 天门后面不是天，是另一片破碎的星海：九重天，这只是第一重。想往上走，只能转世重修，带着前世一缕灵识回到苍墟，再把五大灵主打一遍——这一次它们吞下的是第二重天的碎片 |

## 七、飞升之后

天门开了。你踏进去，光从四面八方涌来，灵气像潮水一样倒灌回天上；你身后，苍墟的万兽一只一只安静下来。

可门后不是天。

是另一片破碎的星海，一层叠一层，一直叠到看不见的地方——**九重天**。你站着的，只是第一重。上面还有八重，每一重都塌着，每一重的碎片，都坠在下一层的人间。

你终于明白三万年前那一夜，塌的不止是一座门。

——轮回，第二重天。
