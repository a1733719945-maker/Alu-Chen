# 苍墟 · 猎灵 —— 世界观与剧本

原创设定。框架取自中国修仙小说的通行元素（天门、飞升、境界、洞天、内丹），名物取自公版古籍（《山海经》《庄子》、北斗九星的星名），**不用任何现代小说的专有名词**。

写给游戏里用的文字都要短：一句话能说完的不说两句，台词不超过两行。

---

## 零、一句话

三万年前，人在天坛前"叩天"，要打上九重天；守门的天枢星君把自己碎成五块，关死了天门。
你以为你在猎灵、夺碎片、为了飞升——其实你在重走那一场战争，也在替五个撑了三万年的守门者，结束它们的差事。

---

## 一、开场时玩家知道的（表面的故事）

- 上古之时，天有九重。人间与九天之间立着一座**天门**。
- 三万年前，**天倾**：天门崩碎，撑住天地的**天枢**碎成五块，坠入人间。大地沉进云海，只剩孤岛，后人叫它**苍墟**。
- 五块碎片被五头上古灵兽吞下，它们不老不死，成了**灵主**。碎片的灵气日夜外溢，**兽潮**一次比一次来得早。
- 你是镜湖边**栖霞村**的孤儿。十二年前的兽潮里，你爹娘死在湖上，是守天坛的独眼老猎人**青崖子**把你从水里捞出来的。
- 你醒来本命灵相那天，青崖子说："三万年没人飞升，不是天太高——是门碎了。去猎灵，去炼环，把它们一个一个叫出来。五块碎片凑齐那天，天门重开。"

序章、渡海过场、每章横幅讲的都是这一层。**真相要玩家一边玩一边拼出来。**

## 二、真相：叩天之战

### 时间线

| 时间 | 发生了什么 |
|---|---|
| 三万多年前 | 天门每十年开一次，九天向人间收**灵税**：人间灵脉最好的三成灵气被抽上天。千年才放一个人飞升。 |
| | 收税的是守第一重天门的**天枢星君**，名叫**云岫**。她每十年骑着一条碧鳞蛟下凡。她心软，常把收上来的灵气偷偷还回去一些。 |
| | 人间第一大宗**太初宗**的年轻剑修**沈青崖**，在镜湖边遇见了她。两人每十年见一面，见了三百年。 |
| 三万年前 | 连着三年大旱，灵脉枯竭，人间饿死无数。天上的税一分没少。沈青崖领太初宗十万修士，在镜湖边的**天坛**前叩天——要打上九重天，把这道门拆了。 |
| 叩天之战 | 打了七天七夜。太初宗的战兽**朱厌**撞开了第一道天阙；天上放下了天河的**冰螭**。十万修士死了九成。 |
| 第七夜 | 天上要降下天罚，把整个人间抹平。云岫守在门口：门后是天兵，门前是沈青崖。她挡不住任何一边，于是**把自己碎成了五块**——门的枢纽就是她，她碎了，门就永远关上了：人上不去，天也下不来。 |
| | 碎之前，她最后一击打在沈青崖脸上，把他从正在塌的门里打回人间。他从此只剩一只眼。 |
| 天倾之后 | 天门碎裂的余波把大地震成了孤岛。五块碎片由五头灵兽吞下看守（见第四节）。沈青崖自封修为，隐姓埋名，在栖霞村的天坛边当了三万年的守坛人。 |
| 如今 | 碎片压不住了。灵主一个个被碎片的灵气逼疯，兽潮越来越早。门迟早会自己裂开——那时天罚会接着落下来。 |

### 谁对谁错

没有纯粹的好人坏人：
- 天上收灵税是真的，人间受的苦也是真的；
- 太初宗叩天有它的道理，死了十万人也是真的；
- 灵主不是恶兽，是替云岫守了三万年、快撑不住的**守门者**。**猎杀它们，是给它们解脱。**

|---|---|---|
| **你** | 栖霞村孤儿，青崖子养大。灵相由玩家选 | 开场 |

## 四、五座岛：每个灵主一种情绪、一块真相

每座岛的节奏都一样：到岸 → 青崖子一句 → 探索（残碑、灵环记忆、秘境刻字）→ 叩天打灵主（出场 / 半血 / 临死三句）→ 炼化灵主灵环 → **天枢记忆**过场 → 回天坛，青崖子一句 → 渡海。

### 第一章 · 镜湖 · 碧鳞蛟 ——「等」

- 它是云岫的坐骑。她碎之前把第一块碎片交给它："等人来取，你就可以睡了。"它沉进湖底，一等三万年。
- **出场**：「……不是她。」
- **半血**：「三万年了。她说会有人来取。」
- **临死**：「……是你来取了吗。那我可以睡了。」
- **天枢记忆**：
  1. 一条碧鳞蛟驮着白衣女子从天门里飞下，落在湖面上。「每十年，她下来一次。」
  2. 湖边的少年剑修抬头看她，她偷偷把一捧灵光撒回湖里。「她收走人间的灵气，又偷偷还回来一些。」
  3. 天门在燃烧，她把一块发光的碎片按进蛟的额头。「等人来取。」
- **青崖子·到岸**：「碧鳞蛟三万年没离过湖。它在等什么，我不知道。」
- **青崖子·打完**：「它说……它在等人来取？——没什么。拿着碎片，去落霞林。」（他停了一下）

### 第二章 · 落霞林 · 千目蛛母 ——「记」

- 叩天之战就打在林子上空。它用千只眼睛看完了七天七夜，把每个战死的人都织进网里记着。林子永远停在黄昏，因为网遮住了太阳。
- **出场**：「又有人从天坛那边来了。」
- **半血**：「我替你们记了三万年，你们一个都不记得。」
- **临死**：「你们人……总是忘。网里的名字，替我念一遍。」
- **天枢记忆**：
  1. 天坛前黑压压的修士，旗上一个"初"字。「三万年前，十万人在这里叩天。」
  2. 修士像流星一样冲上天，又像雨一样落下来。「七天七夜。」
  3. 蛛母把坠落的人一个个缠进发光的丝里。「她记下了每一个。」
- **青崖子·到岸**：「落霞林的丝，碰到了别扯。那是……以前的人。」
- **青崖子·打完**：「太初宗。这个名字，很多年没人提了。」

### 第三章 · 苍梧林海 · 朱厌 ——「战」

- 太初宗养来攻天的战兽，沈青崖的坐骑。《山海经》说它"见则大兵"——它就是那场仗。云岫把第三块碎片封进它体内，才压住它的怒气。现在它醒了。
- **出场**：「……天坛又响了。又要打了？好！」
- **半血**：「你的剑法……我见过。」
- **临死**：「告诉那个独眼的——我没输。」
- **天枢记忆**：
  1. 双眼完好的年轻剑修骑着白头红足的巨猿，冲向天阙。「领兵的人，叫沈青崖。」
  2. 巨猿一拳砸开第一道天阙。「朱厌撞开了天门。」
  3. 天门后，白衣女子张开双臂挡在天兵前面。「门后是天兵。门前，是他。」
- **青崖子·到岸**：「朱厌……它以前不是这样的。」
- **青崖子·打完**：「……它还说了什么？」（玩家已经猜到了；他没有否认）

### 第四章 · 朔北冰原 · 冰螭 ——「忘」

- 天河的螭，天兵的坐骑，天倾时跟着天兵一起坠下。它冻住一整片海，把两边战死的人封在冰下——好让活着的人忘掉那一仗。冰原深处冻着年轻的沈青崖留下的剑。
- **出场**：「凡人。你身上有太初宗的味道。」
- **半血**：「冰下面是两边的兵。我让他们睡着。」
- **临死**：「别挖。有些东西，冻着比醒着好。」
- **天枢记忆**：
  1. 天上降下金色的天罚，门开始塌。「第七夜，天上要抹平人间。」
  2. 白衣女子回身一掌，把冲进门的剑修打落，他的一只眼流着血。「她把他打回了人间。」
  3. 她的身体裂成五道光，天门一片片碎掉。「然后，她把自己碎了。」
- **青崖子·到岸**：（背对着你）「朔北的冰下面，有我的剑。」
- **青崖子·打完**：「你都看见了。我就是沈青崖。」

### 第五章 · 归墟 · 玄鲲 ——「归」

- 北冥最老的鱼。云岫把自己的"心"——最后一块碎片——交给它，它沉到万水归处，把碎片藏在世界最底下。
- **出场**：「你是第一个走到这里的人。」
- **半血**：「她说，要是有一天有人把我们都杀了……」
- **临死**：「……那就说明，人间已经不怕天了。」
- **天枢记忆**：
  1. 巨鲲在月下沉入深海，腹中一点紫光。「最后一块，是她的心。」
  2. 天门碎片之间，她对着人间最后说了一句话。「"别来找我。好好活着。"」
  3. 三万年后，独眼老人坐在塌了的天坛前，一坐就是一天。「他没听。」
- **青崖子·到岸**：「最后一块了。拿到它，回天坛。我有话跟你说。」
- **青崖子·打完**：见第五节。

## 五、结局：天坛前的选择

五块碎片齐了，回到栖霞村的天坛。青崖子站在当年叩天的地方：

> 「三万年前，是我带着十万人在这里叩天。
> 她为了挡住我，把自己碎了。
> 碎片凑齐，她就能醒。门会重开，你也能飞升。
> ……可门一开，天上的账，也会接着算。
> 你来选。」

**重铸天枢**（天门重开，你飞升）
- 五道光合成一个人影。她睁眼，看见白发独眼的他：「……你老了。」他：「你没变。」
- 天门打开，你踏进去——门后的第一重天是一片废墟，没有天兵，只有塌掉的宫阙。那一仗，天上也输了。
- 云岫：「上面……也塌了。」
- 结尾字：**天枢篇 · 终**。轮回 → 天璇篇（往上一重一重，去收拾那场仗留下的残局）。

**让她安息**（碎片散入苍墟，天门永闭）
- 你把碎片埋进天坛的土里。五道光渗进苍墟的山川，灵气留在了人间，兽潮从此停了。
- 青崖子在天坛前坐下：「她说过——等人来取，就可以睡了。」他没有再起来。
- 很多年后，镜湖边的孩子问：天上有什么？没有人知道了。
- 结尾字：**天枢篇 · 终**。轮回 → 天璇篇（下一世的苍墟没有兽潮，可天上的裂缝还在，第二重天的碎片开始往下掉）。

两个都是好结局，只是不一样。联机时每个人各选各的，存在自己的存档里。

## 六、轮回：北斗九重

九重天对应北斗九星（公版星名），每轮回一次，往上一重：

| 重 | 星名 | 篇名 |
|---|---|---|
| 一 | 天枢 | 天枢篇（第一周目） |
| 二 | 天璇 | 天璇篇 |
| 三 | 天玑 | 天玑篇 |
| 四 | 天权 | 天权篇 |
| 五 | 玉衡 | 玉衡篇 |
| 六 | 开阳 | 开阳篇 |
| 七 | 摇光 | 摇光篇 |
| 八 | 洞明（左辅） | 洞明篇 |
| 九 | 隐元（右弼） | 隐元篇 |

- Boss 名字后面：「第二重天 · 天璇」。
- 轮回后，灵主出场第一句换成：「又是你。」（第三重起：「这是第几次了？」）
- 轮回后的每一重，碎片是那一重天的守门星君留下的——她们是谁、为什么也碎了，留给以后的更新。

## 八、游戏里的每样东西是什么

| 游戏里 | 世界观里 |
|---|---|
| 等级 / 修为 | 境界。每十级一个大境界，门槛上要炼化一枚灵环 |
| 灵环 | 灵兽一生的灵气，也带着它的记忆 |
| 猎灵榜（L） | 各岛猎户和宗门的悬赏 |
