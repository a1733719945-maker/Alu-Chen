# 第二批（2026-09-29）：剩下 7 把暗器 + 21 种灵兽

**这一批都不需要骨骼，用哪个工具生成都行**（混元、Tripo、Meshy 都可以）：
- 暗器：后坐、切枪、检视都是代码动整把枪；流沙机弩的转轮、天心泪的泪滴，我按位置从模型里切出来单独动
- 灵兽：动作全部用代码做（和跳尸一样）：鱼 / 蛇 / 藤身体波浪摆，鸟 / 蛾 / 蝠 / 鳐扇翅膀，兔 / 蟾一蹦一蹦，蛛 / 蟹八条腿交替迈，四条腿的腿按位置切开前后摆。
  **所以姿势很重要**，每组的姿势要求写在组名下面
- 唯一例外：**山魈**是人形，最好用混元生成 + Studio 绑骨骼（只导出一个待机动作就行，走、跑、攻击我用朱厌那套）
- 雪原狼、雪猱不用生成：用追风狼、山魈换颜色

**通用**：写实风格，带 PBR 贴图，导出 GLB，1 万~3 万面；单独一个，不要底座、不要地面、不要其他东西。
**小技巧**：先用豆包 / 即梦把同一段话生成一张"纯白背景、侧面全身"的图，再图生 3D，比直接文生 3D 稳。
**文件名**照下面起，放进 `tools/incoming_models/`。
