Mac 版 —— 2026-09-28
=========================

下载页（和 Windows 版同一个页面）：
https://github.com/a1733719945-maker/Alu-Chen/releases/tag/latest-claude-douluo-multiplayer-game-lza8mi
下载 CangxuHunter-Mac.zip（两百多兆）。

1. 双击 CangxuHunter-Mac.zip 解压，得到“苍墟·猎灵”。建议拖进“应用程序”文件夹。
   Intel 芯片和 M 芯片（M1/M2/M3/M4）的 Mac 都能用，要 macOS 11 或更新。

2. 第一次打开会被系统拦住（我们没有交苹果每年 99 美元的开发者费，所以没有苹果的公证，游戏本身是安全的）：
   - 提示“无法验证开发者”或“Apple 无法检查其是否包含恶意软件”：
     点“完成”，打开“系统设置 → 隐私与安全性”，拉到最下面，点“仍要打开”，输入开机密码。
     （macOS 14 及更早：也可以在 app 上按右键 →“打开”→“打开”。）
   - 提示“已损坏，无法打开”：打开“终端”，输入
       xattr -cr
     后面打一个空格，把“苍墟·猎灵”拖进终端窗口，按回车。然后再双击打开。
   只需要做一次，以后直接双击。更新时下载新的 zip，用新的替换旧的，存档不会丢。

3. Mac 上的操作和 Windows 一样，另外：
   - 蹲用 C（Mac 上按住 Ctrl 再点鼠标会变成右键，所以别用 Ctrl 蹲着开枪）。轻点 C 或 Ctrl 翻滚。
   - 用触控板也能玩，但强烈建议插一个鼠标。
   - 卡的话：Esc → 设置 → 画面，把“画质”调低，或把“渲染分辨率”拉低。
   - 全屏：F11（有的 Mac 要按 fn + F11），或者设置里勾“全屏”。

4. 存档在：~/Library/Application Support/Godot/app_userdata/苍墟·猎灵/
   Mac 和 Windows、安卓的朋友可以一起联机。

  有的手机还会弹"安全扫描 / 风险提示"：选"继续安装"或"仍然安装"。游戏没上架应用商店，所以会这样提示。

- 苹果手机暂时没有（要苹果开发者账号才能发给朋友装）。

手机要求
- 安卓 7.0 以上、64 位（近五六年的手机基本都是）。
- 画面比较重：最好是近三年的中高端手机。卡的话：暂停 → 设置 → 把"渲染分辨率"调低（比如 0.6），画质保持"低"。
- 玩久了会发热、耗电快，这是 3D 游戏的正常现象。

触屏操作（横屏）
- 左手：左半边屏幕按哪里哪里就是摇杆，往前推到圈外就是冲刺。
- 右手：右半边空白处滑动转视角。按住开火键 / 开镜键的时候手指也能拖动转视角（边打边瞄）。
- 右下一圈按钮：
  大圆圈 = 开火（里面写着子弹数）；开镜（点一下开、再点一下关）；上箭头 = 跳（水里是往上游）；
  下箭头 = 蹲（轻点是翻滚，按住是蹲，水里是往下潜）；转圈箭头 = 换弹；
  钩子 = 引魂索（按住蓄力、松开甩出去；咬钩时钩子键会闪金光，赶紧点）；
  右边竖着三个 = Q / E / F 三个神通（转圈的是冷却，发蓝是灵力不够）。
- 旁边有能交互的东西（暗器铺、祭坛、船、灵环、救队友）时会冒出"交互"键，救人要按住。
- 左边"回血"键吃药；底部中间是物品栏 1~5，直接点；"丢"= 把手上的东西丢出去（丢给队友或丢进收购箱卖钱）。
- 点右上角小地图 = 打开大地图，再点一下关掉。
- 左上角：暂停键；"菜单"键里有灵相、成就、猎灵榜、换鱼饵、排名（按住看）、大地图。
- 打开任何面板（暗器铺、灵相……）直接用手指点；左上角"返回"或手机的返回键 = 关掉 / 暂停。
- 狙击镜开着的时候会多一个"屏息"键，按住镜头稳。
- 辅助瞄准：开火、开镜或转视角的时候，准星附近的灵兽会被轻轻吸过去。不想要可以在设置里关。
- 设置 → "手机 · 触屏"：滑屏灵敏度、按钮大小、辅助瞄准、界面大小。

- 饱食度：会饿，饿了不回血。打死灵兽常掉烤肉，按 4 拿出来左键吃。
- 悬赏（左上角）、精英灵兽（名字带"王"，固定刷新，必掉灵骨）、兽潮、猎灵录（K 面板）都是可选目标。

成长节奏
--------
- 几分钟一个小提升：暗器铺的升级（每把 4 项 × 5 级）、配件、灵骨、升级。
- 十几二十分钟一个大提升：新灵环（新神通 + 特效升级）、打 Boss、新暗器、新岛。
- 后面的岛灵兽血厚得多、给的钱和修为也多得多；在旧岛练级会越来越慢，早点去新岛更快。

暗器
----
- 袖箭、千丝雨针第一章就能买，连机神弩第二章，流光翎第三章，穿云弩第四章。
- 每把都有后坐图案：连射时准星往上跳、左右摆，往下拉鼠标压住；停火自动回正。第一发最准。
- 移动、跳起来射击会散，蹲下更准，开镜最准。

和朋友联机
----------
1. 一个人在主菜单点"创建联机房间"，进游戏后按 Esc 能看到 4 位房间码，发给朋友。
2. 朋友在主菜单输入房间码，点"加入房间"。
3. 服务器是免费的，15 分钟没人玩会休眠，第一个连接的人要等 1 分钟左右。
4. 坐船要所有人都到船边按 F 选同一个目的地，人齐了一起出发。倒地后队友按住 F 救你。
