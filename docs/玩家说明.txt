斗罗大陆·猎魂 —— 第十二版：暗器大更新 + 第十一版的问题修好了（2026-09-28）
=======================================================================

你上次说的问题
--------------
1. 秘境卡脚、魂兽卡在墙上：秘境地面的碰撞以前比看得见的地面高了一米（人和魂兽出生在碰撞里面），修好了；
   柱子、墙、入口台子的碰撞也对齐了；万一还有魂兽卡住 3 秒不动，会被拉回场地中间。
2. 猎魂路太好找：现在要自己追踪——
   - 猎魂榜只告诉你它"在「某片栖息地」一带出没"，罗盘上不标。
   - 它走过的地方每十几米留一处发光的爪痕（走到 35 米内才看得见），走过去按 F 查看：它往哪个方向走了、痕迹新不新。
   - 看过 3 处爪痕就"锁定"它 45 秒（罗盘上出现「猎」和距离）；锁定时再看爪痕 +20 秒。
   - 它半分钟吼一声，140 米内听得到，只知道大概方向；走到 30 米内直接看得到它。
3. 狙击打远处不显示伤害：狙击、35 米外、爆炸、蓄满的一箭，伤害数字一定飘，还有一声清脆的命中音。
4. 螃蟹不打人：测过其实会咬，但螃蟹这种"冲撞"型魂兽贴身时经常只顶不咬，现在贴身会直接咬。
5. 伤害基本秒杀：魂兽血量有了下限——按你最强那把暗器算，至少要打三四枪（年份越高越多），不会再一枪一只。
   打得慢的暗器（狙击、观音泪）不会因此要打五六枪。第三章往后秘境小怪下手稍微轻一点。

新暗器（五把，每把一种新玩法）
------------------------------
- 梅花袖箭（第一章，副手，按 2）：扣一下连出三箭，三箭都爆头最痛。
- 龙须针（第二章）：精确射手，开镜几乎没有散布，爆头 ×2.6，一针穿两只。
- 子母追魂夺命胆（第三章）：打到哪炸到哪（4.5 米），炸完再散出三颗子胆各炸一次，专打一群。一颗一颗往里装。
- 含沙射影（第四章）：机枪，一匣九十发，按住越打越快（一秒多转到最快），很重、跑得慢。
- 观音泪（第五章）：按住左键蓄力，松开出手；蓄满（准星外一圈变金色）伤害 ×5、一箭贯穿一路上所有魂兽。
袖箭和梅花袖箭都是副手：按 2 在两把之间换；按 1 在主暗器之间换。

暗器熟练度
----------
用哪把暗器打死魂兽，哪把涨熟练度（年份越高、爆头、空中、魂兽王涨得多），最高 10 级：
2 级换弹快 5% · 3 级送皮肤「精钢」· 4 级开镜快 8% · 5 级伤害 +3% · 6 级送「黑金」· 7 级后坐 -8% · 8 级伤害再 +3% · 9 级换弹再快 5% · 10 级送「唐门大师 · 流光」。
暗器铺卡片上有熟练度条；升级时屏幕中间会提示。

皮肤（不再只是换颜色）
----------------------
每款皮肤现在是一种材质：金属反光、镜面、清漆、木纹、碳纤维编织、大马士革钢纹、玉石里的发光玉脉、龙鳞、
会随角度变色的珠光，还有会动的：流光、熔岩裂缝一明一暗、星云、魂导回路扫光、暗影流烟、水波、极光……
- 暗器铺 → 外观：上面选哪把暗器，左边是能拖着转的 3D 预览——点任何一款皮肤先看效果，喜欢再买。
- 每把暗器可以穿不同的皮肤（"装到这把"），也可以"所有暗器都用"。
- 新皮肤：碳纤维、镜面铬、大马士革、渐变镭射、熔岩、幻彩珠光、魂导回路；熟练度皮肤：精钢、黑金、唐门大师 · 流光。
- 以前的皮肤（碧玉、血玉、寒冰、暗影、金龙、星河、Boss 和猎魂录皮肤）都换成了新材质。

自己画皮肤
----------
暗器铺 → 外观 → 自己画：中间是暗器的正侧面，直接在暗器上画（左边是枪尾、右边是枪口，另一面是镜像的）。
- 画笔、喷枪、橡皮、图章（星、圆、条纹、闪电、心、云纹）、写字（自己输入）、铺满底色。
- 颜色、大小、不透明度可以调；颜料质感：哑光 / 亮漆 / 金属 / 镜面。
- Ctrl+Z 撤销。右边是 3D 效果。"保存并穿上"以后这把暗器就穿着你画的。
（队友看你手里的小暗器是原色——画的图在你自己电脑上。）

新配件（暗器铺 → 配件，先选暗器，按部位分好了）
------------------------------------------------
- 瞄具：4 倍镜
- 枪口：补偿器（左右抖动 -40%）、消音器（枪声小、没有枪口火光）
- 枪管下：斜握把（开镜快）
- 弹匣（新部位）：扩容弹匣（+50% 弹量，换弹慢一点）、快拔弹匣（换弹快 30%）、魂晶弹匣（伤害 +6%，弹量少一点）
- 枪托（新部位）：轻型枪托（开镜快、跑得快）、战术枪托（后坐 -18%）

挂件
----
暗器铺 → 外观 → 挂件：红流苏、玉佩、金铃、柔骨兔、魂环挂坠（你最高魂环的颜色）、唐莲。挂在暗器上，跑、跳、开火都会晃。


斗罗大陆·猎魂 —— 第十一版：猎魂 + 秘境（2026-09-28）
=================================================

玩法整个换了：野外不再刷怪，刷怪只在秘境里；魂环要自己挑魂兽去猎。

每座岛怎么玩
------------
1. 猎魂（换魂技的地方）
   - 按 L，或者走到码头边的"猎魂榜"告示牌按 F。
   - 榜上列着这座岛能猎的魂兽，每只写着"你吸收它的魂环会领悟哪个魂技"——想要哪个魂技就猎哪只（原著里唐三也是为了蓝银草专门去找曼陀罗蛇）。
   - 每只有两个年份可选：年份高的更难打，魂技更强。
   - 挑好后它会出现在岛上很远的地方，地图上不标位置：要自己追踪（看第十二版的说明：找爪痕、锁定）。
   - 打倒它（大招前地上出红圈能躲，引魂索能捆住它）→ 掉魂环、王魂、魂骨、一大截修为。
2. 吸收魂环：走到魂环旁边按 F，要站着不动（能开枪）。
   - 单人 10 秒，只来一小波魂兽。
   - 联机 25 秒，魂兽会一波波冲向吸收的人，队友要护法；吸收的人倒下就失败，魂环掉回原地。
3. 秘境（刷修为、金魂币、魂骨的地方）
   - 地图、罗盘上的「秘」，每座岛三个入口：一层、二层、三层，年份一层比一层高，奖励也更多。
   - 走过去按 F 进去：三波魂兽从兽门冲出来 → 秘境之主 → 宝箱（回血丹、唐莲，二层以上有魂骨）+ 一大笔金魂币和修为。
   - 每次进去有一个随机词条：兽潮 / 坚甲 / 陨星 / 疾风 / 狂暴，奖励跟着涨。会记你最快的通关时间。
   - 联机：一个人开了秘境，队友从同一个入口随时进来帮忙；人数越多魂兽越多。
   - 在秘境里倒下会回码头；所有人都倒下秘境就失败。从南边的台子按 F 可以随时离开。
4. 主线：通关一次秘境 → 修炼到这一章的等级 → 祭坛召唤 Boss → 渡船去下一个岛。

暗器找回来了
------------
以前倒下会把手里的暗器丢在地上、谁捡到归谁——你的存档因为这个把暗器全丢了，只能空手打（这就是"打不动、一来就死"的一大原因）。
现在倒下不丢暗器；以前买过、升级过的暗器第一次进游戏时全部还给你。

还保留的
--------
引魂索钓魂兽（空中连击、卖钱）、暗器铺、魂骨、附魔、成就、连击评级、猎魂录。
上一版的仇恨范围、魂力护体（等级越高越抗打）、第二章不中毒这些都还在。

斗罗大陆·猎魂 —— 第六版：组队猎魂兽王（2026-09-27）
=================================================

核心玩法改了：每座岛的重点是和队友一起猎杀"魂兽王"（像《怪物猎人》，也像原著里史莱克七怪进山猎魂环）。

- 魂兽王：每张图 3 只（左上角列着名字、多远、在哪个方向，地图上标"王"）。体型大、血厚，有自己的招式：
  震地（脚下红圈）、扑杀（砸到你站的位置）、魂兽本身的独门招式；半血暴怒（更快更狠，叫来小弟、放冲击环）；
  四分之一血会逃回巢穴养伤——追上去补刀。6 分钟后重生。
- 猎杀奖励：必掉魂环（卡在瓶颈、年份够的人每人一个）、必掉魂骨、每人一个"王魂"，修为和金魂币 ×12。
  第二环往后需要的百年 / 千年 / 万年魂环，主要靠猎魂兽王拿。
- 捆魂（配合）：引魂索现在能直接钩魂兽。
  · 钩小魂兽：拽上天，接着空中连击（受伤 +20%）。
  · 钩魂兽王：单人一根索就能捆住；联机要两个人在 3.5 秒内一起拽住，把它按在地上 5 秒、受到伤害 +50%。挣脱后 18 秒内捆不住。
- 魂导附魔（暗器铺 → 附魔）：用王魂给暗器附魔，命中有几率触发：
  缠魂（柔骨兔 / 月光蛾 / 地穴魔蛛 / 碧磷蟾王）、雷鸣（风铃鸟 / 夜翼魔蝠 / 海魂鸥王）、裂伤（疾风魔狼 / 疾爪龙 / 雪原狼王）、
  爆裂（铁甲犀 / 金刚猿 / 铁钳蟹王）、焚魂（鬼眼鹿 / 冰角鹿 / 疾爪龙王）、震魂、霜寒……想要哪种附魔，就去猎对应的魂兽王。
- 在打魂兽王时，屏幕顶上会出现它的血条，音乐也会换成战斗曲。

斗罗大陆·猎魂 —— 第五版（成神之路）

第五版改了什么（先看这里）
--------------------------
- 没有清单任务了。目标只有一个：修炼到 100 级、吸收十个魂环 = 成神（通关，有结局动画）。
  每张图的祭坛：等级够了（第一章 15 级、第二章 35、第三章 55、第四章 75、第五章 95）就能召唤 Boss，
  打赢了渡船就能去下一个岛；以前去过的岛随时能坐船回去。Boss 打完 3 分钟后能再召唤（刷魂骨、魂环）。
- 魂技自己选：按 K 打开武魂面板，每个魂环的魂技旁边有 Q / E / F 三个按钮，点哪个就装到哪个键上。
  Q、E、F 三个键各放一个魂技，左下角显示图标和冷却。（F 旁边有能交互的东西时是交互）
- 魂环：十年白、百年黄、千年紫、万年黑（发暗红光）、十万年红。
  第一环十年；二三环百年；四五环千年；六到九环万年；第十环十万年。
  魂兽被打死按年份概率掉魂环。卡在瓶颈、年份够的会优先掉给你；用不上的魂环走过去按 F 能"炼化精华"涨修为，30 秒后散掉。
- 所有东西都能卖：暗器铺里点"卖出"（包括袖箭）；东西按 T 丢进收购箱也能卖。卖了 / 丢了 / 送人了都能再买，
  升级和配件记在存档里，买回来还在。一把暗器都没有就空手打（左键出拳）。
- 配件要买（暗器铺 → 配件）：红点、全息、2 倍镜、狙击镜、制退器、垂直握把、激光。默认只有机械照门。
  狙击镜 / 2 倍镜开镜后是全屏瞄准镜（不会晕），狙击镜开镜时滚轮调 4~12 倍，调好会记住。
- 每种魂兽都有自己的招（凶暴的和王会用）：出招前会停下、发光、头顶冒招式名、地上出圈——
  红圈是伤害，紫圈是控制（定身、致盲、封魂技、减速、拖拽）。翻滚（轻点 Ctrl）或跑出圈就能躲开。
  例：风铃鸟音波震退、月光蛾磷粉致盲、鬼藤缠绕定身、狼嚎让附近魂兽更快更狠、疾爪龙扑杀、碧磷蟾长舌卷人、
  幽灵鳐电击封魂技、海魂鸥叼走金魂币（打下它能多拿回来）……被定身时连按空格能提前挣脱。
- 成就（按 J）：三十多个，完成有金魂币奖励。
- 连杀：5 秒内接着杀，每多一只多 15% 金魂币。
- 升级有金光，吸收魂环有天降光柱和全屏闪光；万年魂技是黑红魂火，第十魂技是金色神光。
- 新的开船过场（三个镜头）和成神结局动画；碧磷沼、毒沼的岸边改成缓坡，掉下去能走上来。

怎么打开
--------
1. 把整个压缩包解压到一个文件夹里（不要直接在压缩包里双击）。
2. 双击 DouluoHunter.exe。
3. 第一次运行时 Windows 可能提示"Windows 已保护你的电脑"：点"更多信息"，再点"仍要运行"。
4. 电脑带不动（卡）：Esc → 设置 → 画质 改成"中"或"低"。

怎么玩
------
- 按住 G 蓄力，松开把引魂索甩出去。看路牌：每个地方住着不同的魂兽。
- 看到 "！" 或者听到风铃声，马上再按 G，把魂兽拽上天，趁它在空中开枪。空中击杀、连击、爆头、远距离都有额外奖励。
- 鱼饵：每次咬钩消耗一个。青草饵免费但基本只有十年；血腥饵（凶、奖励高）、魂晶饵（千年多）、金骨饵（魂骨兽多）在暗器铺买，按 B 换。
- 饱食度：会饿，饿了不回血。打死魂兽常掉烤肉，按 4 拿出来左键吃。
- 悬赏（左上角）、精英魂兽（名字带"王"，固定刷新，必掉魂骨）、兽潮、猎魂录（K 面板）都是可选目标。

成长节奏
--------
- 几分钟一个小提升：暗器铺的升级（每把 4 项 × 5 级）、配件、魂骨、升级。
- 十几二十分钟一个大提升：新魂环（新魂技 + 特效升级）、打 Boss、新暗器、新岛。
- 后面的岛魂兽血厚得多、给的钱和修为也多得多；在旧岛练级会越来越慢，早点去新岛更快。

暗器
----
- 袖箭、暴雨梨花针第一章就能买，诸葛神弩第二章，孔雀翎第三章，追魂穿心弩第四章。
- 每把都有后坐图案：连射时准星往上跳、左右摆，往下拉鼠标压住；停火自动回正。第一发最准。
- 移动、跳起来射击会散，蹲下更准，开镜最准。

和朋友联机
----------
1. 一个人在主菜单点"创建联机房间"，进游戏后按 Esc 能看到 4 位房间码，发给朋友。
2. 朋友在主菜单输入房间码，点"加入房间"。
3. 服务器是免费的，15 分钟没人玩会休眠，第一个连接的人要等 1 分钟左右。
4. 坐船要所有人都到船边按 F 选同一个目的地，人齐了一起出发。倒地后队友按住 F 救你。
